# Microcopy-style-guide
🌷 StudyNest – Microcopy Style Guide

UI/UX Design Project

📌 Project Overview

This project is a simple Microcopy Style Guide created for StudyNest, a student productivity app concept.

The purpose is to understand how small text elements can improve communication between an application and its users.

✨ What This Project Covers

- Buttons: Clear and meaningful action labels.
- Error Messages: Friendly and helpful error communication.
- Empty States: Encouraging messages when no content is available.
- Voice and Tone: Consistent and user-friendly communication.

🎨 Design Approach

- Simple and easy-to-understand language.
- Friendly and supportive tone.
- Clear Do's and Don'ts comparisons.
- Soft lavender and white visual theme.
- Clean and minimal layout.

🛠️ Tools Used

- Figma
- Figma AI

💡 What I Learned

I learned how to write effective microcopy for different situations in an application.

This project helped me understand that good UX writing is not just about choosing words. It is about making users feel guided, informed and comfortable.

🎯 Project Goal

To create a simple writing guideline that helps maintain clear, consistent and user-friendly communication throughout an application.
